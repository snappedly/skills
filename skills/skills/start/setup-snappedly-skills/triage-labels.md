# Triage labels

Snappedly skills use five canonical triage roles. Map each role to the label string used by this repo's tracker.

| Canonical role | Label in this repo | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the work. |
| `needs-info` | `needs-info` | The reporter must provide more information. |
| `ready-for-agent` | `ready-for-agent` | The work is specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | The work needs human implementation or judgment. |
| `wontfix` | `wontfix` | The team will not action the work. |

Change the right-hand column when the tracker uses different strings.
