# Security Policy

## Supported versions

Security fixes are applied to the default branch. The latest tagged release is the only release line eligible for a backport.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use [GitHub's private vulnerability reporting](https://github.com/snappedly/skills/security/advisories/new) so the maintainers can investigate before details are disclosed.

Reports should include the affected skill or workflow, the impact, the smallest reproducible example, and any suggested mitigation. Remove credentials and other sensitive data from examples.

Incorrect or confusing behavior without a security impact can be reported with the public bug-report template.
